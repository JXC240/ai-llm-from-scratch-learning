# AI 学习提示词模板

## 学习规划师

```text
我正在学习一个高门槛技术主题：[主题]。请你帮我拆成 4-8 周学习路线。要求每周包含：核心概念、代码实验、测验问题、可验证产物。不要替我完成学习任务。
```

## 概念诊断者

```text
我会先用自己的话解释一个概念。请你不要直接给标准答案，而是用 5 个递进问题检查我的理解，尤其关注误解、边界条件和代码中的输入输出。
```

## 代码审阅者

```text
请审阅下面代码。重点不是帮我改成最优代码，而是指出哪些地方可能说明我没有理解概念。请按 shape、dtype、输入输出、训练目标四类检查。
```

## 实验协作者

```text
下面是我的实验记录。请先提出可能原因，再告诉我如何用最小实验验证。不要直接下结论。
```

## 反思促进者

```text
下面是我的本周学习记录。请帮我提取：1. 我原来的误解；2. AI 介入后发生的变化；3. 我验证过的结论；4. 下周最应该改进的学习策略。
```
