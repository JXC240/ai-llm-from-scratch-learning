# 学习习惯基线

## 我过去如何学习复杂技术

- 通常如何开始：就是一边看视频，一边在jupyter lab 里写代码
- 如何看视频：就是正常看，不懂的在回看一遍
- 如何记笔记：不记笔记，基本上都是在教材上写或者写代码的时候写在jupyter的md里
- 遇到 bug 如何处理：问ai，我不会读bug的问题，我只大概知道bug在哪
- 如何判断自己是否学会：课后练习题，而且我觉得很容易一边学一边忘

## 当前学习 LLM 的主要困难

- 概念困难：概念比较抽象，但能够理解，主要是串联比较难
- 代码困难：我的python没有那么熟练，只是知道大概是个什么东西，自己编码困难
- 数学困难：我的高数和线代都还行，但是不会概率论，什么贝叶斯什么乱起八糟的都不懂，机器学习方法也不知道
- 实验困难：目前没有，设备目前能运行基础代码，5070，1w的电脑
- 时间管理困难：很容易分心，虽然每天的时间很充足，很容易学一会玩一会抖音

## 传统学习痛点

| 痛点 | 具体表现 | 对学习的影响 |
|---|---|---|
| 被动看课 | 容易分散注意力，不知道在讲什么就走神了 | 没学到真东西，假学习 |
| 抄代码但不理解 | 对代码不太懂，因为基础太差，只能抄代码自己写不出来 | 假学习，对知识的理解不够透彻 |
| bug 只想快点修好 | 不真正关心代码到底为什么错 | 没有学到真正的知识，不够全面 |
| 缺少检测 | 不知道 | 不知道 |
| 缺少复盘 | 一边学一边忘，下次写代码上次的东西完全忘记了 | 容易忘 |
