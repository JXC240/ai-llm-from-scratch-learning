# AI 支持复杂技术学习五角色协议

## 角色 1：学习规划师

使用场景：

- 拆解课程学习路线。
- 规划每周目标。
- 识别先修知识。
- 调整学习节奏。

对应证据：

- 学习路线图。
- 周计划。
- 计划调整记录。

## 角色 2：概念诊断者

使用场景：

- 用苏格拉底式追问检查“我是否真的理解”。
- 生成反例。
- 设计小测。
- 解释错误理解的根源。

对应证据：

- AI 追问记录。
- 错题记录。
- 概念修正前后对比。

## 角色 3：代码审阅者

使用场景：

- 审查 tokenizer、attention、GPT block 等实现。
- 指出 shape、dtype、device、loss 相关风险。
- 要求我解释每段代码的输入、输出和作用。

对应证据：

- AI code review 片段。
- Git 提交记录。
- 修改说明。
- 运行结果。

## 角色 4：实验协作者

使用场景：

- 分析 loss 曲线。
- 比较生成样例。
- 解释参数变化影响。
- 提出实验假设。

对应证据：

- 实验日志。
- AI 假设。
- 验证结果。
- 结果截图或表格。

## 角色 5：反思促进者

使用场景：

- 引导每周复盘。
- 帮助识别学习策略变化。
- 总结误解类型。
- 生成下一阶段改进问题。

对应证据：

- 周反思。
- 阶段复盘。
- 最终个人反思。
