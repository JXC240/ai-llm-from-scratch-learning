# AI赋能复杂技术学习的诊断式学习实践：以 LLM from Scratch 为例

副标题：从被动看课到诊断式学习：AI支持下的 LLM from Scratch 复杂技术学习创新实践

本仓库是赛组四“AI赋能学习创新案例”的学习证据库，用于记录一名学生围绕 Sebastian Raschka 的 *Build an LLM from Scratch* 视频课程，开展 8 周 AI 增强学习实践的全过程。

## 一句话定位

本项目不是普通代码仓库，而是一个用于证明“AI 如何让复杂技术学习变得可记录、可验证、可推广”的学习证据库。

## 研究问题

AI 如何帮助学生学习 LLM 这类高门槛复杂技术，并让学习过程可记录、成效可验证、方法可推广？

## 核心成果

- 学习过程：8 周学习日志、问题记录、AI 对话精选案例、Git 提交历史。
- 学习成效：前后测、每周小测、核心代码实验、loss 与生成样例、知识图谱变化。
- AI 作用：AI 五角色协议、AI 发现误解案例、AI 辅助调试案例、AI 错误验证案例。
- 推广价值：提示词模板、学习日志模板、bug 记录模板、同伴试用反馈。
